Maze Generator
==============

Overview
--------
A light weight python-based maze generator making use of stacks.



Specifications
------
Made in Python 3.12
Has command line control of the maze generation

Current tags(Not yet implemented):

-g --growth-enabled : Enables Growth Strength propagation

-s -size N : Size of grid (N > 4)

-interval float : step interval between each draw

-min --min-size int : Minimum size of Grid
